# Loop

## Descripción

Loop es un proyecto web desarrollado en HTML, CSS y JavaScript que consiste en una red social donde las personas pueden compartir ideas, opiniones y conocimientos sobre diferentes temas de interés. Su propósito es ofrecer un espacio de comunicación e intercambio de pensamientos alrededor de áreas como la ciencia, la religión, el arte y el deporte, permitiendo que los usuarios interactúen y conozcan diferentes puntos de vista.

## Principales características

1. **Inicio:** Presenta una breve expplicación de que es Loop y temas más destacados de la comunidad.
2. **Acerca de:** Explica el propósito de Loop y la idea detrás de esta red social.
3. **Publicaciones:** Permite explorar contenido relacionado con ciencia, religión, arte y deporte.
4. **Crear publicación:** Ofrece un espacio para compartir ideas, opiniones y experiencias con otros usuarios.
5. **Perfil:** Cuenta con una sección destinada a mostrar la información del usuario.
6. **Navegación:** Incluye una barra de navegación para facilitar el acceso a las distintas secciones de la página.

## Tecnologías utilizadas

1. **HTML5:** Para estructurar el contenido de la página web.
2. **CSS3:** Para diseñar y personalizar la apariencia visual del sitio.
3. **JavaScript:** Para agregar funcionalidades e interactividad a la página.
